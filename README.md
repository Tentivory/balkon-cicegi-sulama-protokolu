# Balkon Çiçeği Sulama Protokolü

**Sürüm:** 4.7-final-ama-gerçekten-final-değil  
**Statü:** Uluslararası çiçek diplomasisi kapsamında yürürlüktedir.  
**Sertifika:** ISO-9001, ISO-14001 ve "Komşu Ablanın Onayı" (KAO-2026).

---

## 1. Amaç

Bu yazılım, balkonunuzdaki çiçeklerin su ihtiyacını **bürokratik törenle** karşılar.  
Çiçekler oy kullanamaz. Su ister. Bu iki cümle arasındaki gerilim, projenin anayasasıdır.

## 2. Felsefi Dayanak

Bir sardunya, sabah 08:12'de susuz kaldıysa bu bir teknik arıza değil, **protokol ihlalidir**.  
Sistem ihlali tespit eder, damla damla telafi eder, raporu basar, gider.

Kimse sormadan cevap verelim:  
Hayır, bu bir akıllı ev sistemi değildir.  
Evet, `time.sleep` kullanıyoruz.  
Hayır, utanmıyoruz.

## 3. Kurulum

```bash
git clone https://github.com/Tentivory/balkon-cicegi-sulama-protokolu.git
cd balkon-cicegi-sulama-protokolu
python3 sulama.py
```

Bağımlılık: Python 3 ve biraz sabır.

## 4. Çalışma Prensibi

1. Program kendini tanıtır (zorunlu).
2. Listedeki her bitkiye rastgele mililitre su "uygular".
3. ASCII damlalar ekrana dökülür.
4. Diplomatik nota kabul edilir.
5. Komşu şikayeti için bekleme süresi başlatılmaz; sadece ima edilir.

Kaktüs de listede vardır. Su istemez. Yine de bakarız. Protokol herkesi kapsar.

## 5. Güvenlik Uyarısı

- Gerçek saksıya su dökmez.
- Wi-Fi şifresi çalmaz.
- Seçim tahmini yapmaz.
- Yalnızca terminali ıslatır.
